# Knowledge Hygiene

Periodically search the vault and repository for:

```text
confirmed
probably
likely
unknown
TODO
FIXME
candidate
assume
hypothesis
```

For every result, check whether the claim still has its original confidence, whether its evidence link resolves, whether contradictory evidence exists, and whether later prose silently promoted inference into fact.

> A repeated hypothesis does not become evidence merely because multiple AI sessions repeated it.

When drift is found, correct the claim, cite the relevant evidence, update [[Hypothesis Register]] or [[Known Unknowns]], and record consequential changes in a session note.
