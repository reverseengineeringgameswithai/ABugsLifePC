# Function 0x00433790

## Summary

Shared indexed grain-gate update called three times by internal
Level04/City Entrance function `0x00433900`.

## Confirmed

- Dispatcher `0x00418780` case 4 at `0x004187A0` reaches `0x00433900`
  through thunk `0x004012F8`; live City Entrance sets `0x00861C84 = 4`.
- Three calls in `0x00433900` reach this routine through thunk `0x00401D52`.
- Instructions `0x004337D1–0x004337E3` read unsigned grain byte
  `0x0059D9B1`, compute `10 * (gate_index + 1)`, and compare them. Retail
  requirements are therefore `(10,20,30)`.
- The exact lookup replacement retained configured `(1,2,3)` dwords in a
  fresh City Entrance Direct3D process.
- At fixed gate-0 trigger coordinate `(-87622,917,-182181)`, the modified
  profile's accepted runtime leaves state `-1`, animation 2/3 `0/0`, and the
  visible gate closed at grain 0. Grain 1 changes them through state 28 and
  `-128/+128` to state 0 and `-1024/+1024`, with the gate visibly open and
  `NextLife=0` (EXP-137, independently accepted by EXP-138).
- [[EXP-20260815-139 - Static grain-gate trigger geometry]] pins the full
  argument surface from the three immediate-only call sites: `(index, x, z,
  radius, delta_a, delta_b, slot_a, slot_b)` =
  `(0, -71129, -184314, 80, -32, +32, 2, 3)` at `0x00433944`,
  `(1, 354031, 35256, 90, +44, -34, 4, 5)` at `0x00433962`, and
  `(2, 582271, 310212, 100, -28, +32, 0, 1)` at `0x0043397F`.
- Per-gate state dword `0x0059F020 + index*4` gates the trigger test at
  `-1`, is set to `0x20` at `0x004337EF`, and decrements per update while
  animation dwords `0x0059F030 + slot*4` accumulate the deltas. Proximity
  uses helper `0x00416580` (thunk `0x00401A37`) with Flik base
  `0x0059D910`; the grain comparison runs only after proximity passes.
- Gate 0's static center and radius reproduce EXP-137's accepted
  inside/outside boundary between the trigger and approach points.

## Inferred

The three caller indices correspond to the three City Entrance grain gates.
EXP-137 physically confirms index 0 in the modified profile; indices 1/2
carry exact static geometry but no runtime receipts.

## Unknown

Physical behavior for gate indices 1/2, their visible identity, and the
meaning of the animation slots' downstream consumers.
