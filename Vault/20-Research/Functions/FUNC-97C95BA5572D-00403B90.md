# Function 0x00403B90

## Summary

Startup function that parses command-line options, initializes configuration/content-root state, attempts to load `cd.txt`, and exits through a media-insertion dialog when that load returns zero.

## Confirmed

- References `cd.txt` at `0x004C4800`, `Please insert A Bug's Life CD.` at `0x004C47C8`, and `A Bug's Life` at `0x004C47F0`. Evidence: `EXP-20260811-004`, xrefs `0x00403C8C`, `0x00403CA3`, and `0x00403C9E`.
- Calls `0x004ADC30` before calling the loader thunk for `0x004AE240("cd.txt", local_buffer)`. Evidence: `EXP-20260811-004`, address `0x00403B90`.
- A zero loader return calls `MessageBoxA` and then the exit routine `0x004AFF40(0)`. Evidence: `EXP-20260811-004`, control flow.
- The media dialog was observed when the runtime log recorded a failed `R:\\cd\cd.txt` load. Evidence: `RUN-WINE-20260811-233536-GAME-LOG`.
- The function passed this gate when the same executable hash successfully read `R:\PC\BUGS\CD\CD.TXT`. Evidence: `RUN-WINE-20260811-233626-INSTALLED-LAYOUT`.

## Inferred

- `cd.txt` is a startup media/content sentinel. Its contents have not been interpreted.
- This function is a one-time initialization stage rather than the complete application initializer.

## Unknown

- Meaning and validation, if any, of the bytes read from `cd.txt`.
- All command-line option meanings.
- Whether the retail installer affects state used by this function.

## Later findings (2026-10-02 audit pointer)

- [[EXP-20260816-143 - Automatic Direct3D startup static audit]] and
  [[PC FMV playback]] answer the command-line question for this hash: the
  parser reads the tail from `0x0059F738`, splits on `" -"`, compares with
  case-sensitive `lstrcmpA`, and knows only `cheat` (`0x005A923C`), `log`
  (`0x008620AC`), `mpeg` (`0x004ED2A0`, FMV off) and `high` (`0x0055C784`).
- [[86Box Win95 RE harness]] (Win95 guest, 2026-08-18): with a detected CD-ROM
  drive the gate reads `D:\pc\bugs\cd\cd.txt` and errors if that fails; with
  no CD drive it falls back to `C:\PC\BUGS\CD\CD.TXT`.
- EXP-20261001-006: this
  function also resets the `RAND.DAT` cursor `0x00599C60` to `0x0081B428`
  (`0x00403C73`); the other reset is level start `0x0042E5C0`.
- The `cd.txt` contents and the retail installer's effect are still open.
