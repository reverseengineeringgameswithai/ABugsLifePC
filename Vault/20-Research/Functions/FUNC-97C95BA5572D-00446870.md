# Function 0x00446870

## Summary

Uses a caller-supplied object's first dword as a generic resource-header index
and writes fixed nonzero values to the same retained-entry pattern as
`0x004467E0`.

## Confirmed

- `0x00446874-0x0044687D` selects `0x005B18E0 + I * 4` from the supplied
  object's first dword and reads header `+0x04`.
- The first loop writes value 1 to the selected stride-`0x50` entry pattern;
  the later loop writes value 2 to three words.
- M2.41's fixed slot-63 call is `0x00415EFF`. Native gate
  `0x00415E50` requires the slot first dword to equal `0x23`, so exact zero
  cannot reach this reader through that call.
- The call occurs before fixed-pool update `0x0041EC40` and before the outer
  normal branch calls M1 coordinator `0x0044D430`.

## Inferred

This is the nonzero-state counterpart to `0x004467E0`. The written-state
meaning is not established.

## Unknown

- Semantic meaning of written values 1 and 2.
- Visible or behavioral effect of the retained-entry changes.
