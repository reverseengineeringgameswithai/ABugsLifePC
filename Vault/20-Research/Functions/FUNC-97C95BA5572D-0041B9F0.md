# Function 0x0041B9F0

## Summary

Updates later fields for one record under mode bit 1 and removes a record from
the active pointer list under mode bit 2. The mode-2 branch can conditionally
zero the record first dword.

## Confirmed

- `0x0041BBAD-0x0041BBB2` gates the removal branch on mode bit 2.
- `0x0041BBB4-0x0041BBBA` writes zero to record `+0x00` only when record
  `+0x62 == 0`.
- The removal branch clears `+0x6E` and `+0x5A` and removes the pointer from
  the list rooted at `0x0059D7E0`.
- The removal branch does not write record `+0x5C` or `+0x44`.
- Direct calls at `0x0041EEC6` and `0x00429E00` pass mode 1 and cannot reach
  the first-dword zero. `0x0041EEE4` passes mode 2 and can.

## Inferred

The mode-2 branch structurally removes/deactivates an active-list record.
Complete lifecycle and field semantics remain unknown.

## Unknown

- Semantic meaning of modes 1 and 2.
- Meanings of record `+0x62`, `+0x6E`, and `+0x5A`.
- Which unchanged scenes realize the M2.40 conditional zero path for slots 2
  or 3.

## 2026-08-16 addition from EXP-20260816-172

Mode 1 is the reinitialise half. It emits positional calls through
`0x0042AA50`, resets `+0x1C`, `+0x24`, `+0x48` and `+0x49`, and then runs a
per-type switch at `0x0041BAF0` (byte table `0x0041BC48`, jump table
`0x0041BC18`) whose domain is exactly type 6..41 — the same window the builder
`0x0041C420` uses. Exactly eleven types take a non-default arm (6, 9, 10, 13,
15, 17, 19, 34, 37, 39, 41); **all eleven** set `+0x44` and **all eleven**
select a frame sequence into `+0x4C`, its first byte shifted left 16 into
`+0x40`, and a signed word into `+0x4A`. The default arm at `0x0041BBA7` does
neither — it writes only `+0x4A = 0xFFFF`.

The `dec WORD PTR ds:0x0059D99E` at `0x0041BA23` is **conditional**: it lies
inside the `cmp WORD PTR [esi+0x6e],0x3E6 / jne` branch at
`0x0041BA0A`-`0x0041BA10`, so it runs only when `+0x6E` is exactly `0x3E6`
(998). No per-type default produces that value — they are all 1..8 — and its
producer is **Unknown**.

`0x0059D99E` itself is **not** interpreted: it has writers in at least eleven
other functions, including `cmp ...,0x39 / mov ...,0x38` at `0x004361CB` and
`add ...,0xFFF9` at `0x00438825`.

  contact-kill routine `0x0041C9B0`. The only immediate writes of 998/999 to

  audit disassembly scan).
