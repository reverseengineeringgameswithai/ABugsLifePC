# Function 0x00441D20

## Summary

The options screen. Its own log line names it "Options_Scr" (`0x004DDB80`,
"ROUTINE : --- Start Options_Scr ---"). The proposed name is the binary's
string, not an interpretation.

**Extent:** `0x00441D20` to the next function at `0x004429D0` (Ghidra
export bounds).

## Confirmed

- Prompts: "select option and press enter" (`0x004DDB44`), "() - to change"
  (`0x004DDB30`), "press enter to accept changes" (`0x004DDB0C`) and "press
  esc to go back" (`0x004DDAF0`).
- Loads `level00\level.raw` and `level00\level4.raw` for its art.
- **Rows.** Five rows at y = 70, 95, 120, 145, 170 (words `0x004DD5A0`). On
  the first, Enter calls the controls screen
  [[FUNC-97C95BA5572D-00430DF0]] (`0x004421E1`).
- **Option bytes.** Reads and writes `0x004D84E5`–`0x004D84EA`
  (EXP-20260930-007).

## Inferred

That the other four rows are the settings stored in `0x004D84E5`–`0x004D84EA`
("() - to change").

## Unknown

The other rows' labels are not in the string table. The screen draws them
as "music volume", "sfx volume" and "graphics options" (seen 2026-10-18).
What the fifth row position is for is unknown.

## Callers

Thunk `0x004018AC`, called once from `0x004444EA` in the level select
`0x00443B40`, when the carousel exit value is −3: carousel position 0
(EXP-20261001-003).

## Callees

Not enumerated beyond the controls screen.

## Relevant strings

The four prompts above and the log line.

## Relevant imports

None directly.

## Structure accesses

Row table `0x004DD5A0`; option bytes `0x004D84E5`–`0x004D84EA`.
