# Function 0x00445020

## Summary

Loads a scene-selected batch of character and plant resource pairs into a
shared arena and object table.

## Confirmed

- `0x004671D0` calls this function through thunk `0x00401CA8` at
  `0x004679C2`, passing pointers to the current object index and resource-arena
  cursor.
- Before that call, `0x004671D0` clears the object index at `0x0046782C`.
  This function reads selector global `0x00861C84` at `0x004450AE`, selects
  one of four exact Flick-family base strings, and passes resource ID zero to
  `0x00444C40` through the converged call at `0x00445143`. The accepted
  Training `chars\flick` request uses the default arm whose string push is at
  `0x004450EC` (`EXP-20260812-034`).
- The other exact arms select `chars3\flickd` for values 2/3,
  `chars4\flickp` for 4/5, and `chars3\flickp` for 6/10/11/14. These are
  control-flow facts, not semantic identities for the selector or paths.
- Calls `0x00416100` at `0x00445601` to obtain a `-1`-terminated plant ID
  list, then switches IDs 1–14 to exact `plants`/`plants2` base strings.
- Selected shared-scene call sites are plant 04 `0x0044575E`, plant 05
  `0x004457B5`, plant 06 `0x0044580C`, and plant 10 `0x00445968`. All reach
  `0x00444C40` through thunk `0x004018A7`.
- The exact base-string addresses and numeric resource IDs are recorded in
  `static/exports/BIN-97c95ba5572dce63/M2-plant-resource-static-trace.md`.
- `EXP-20260812-020` changes only Training DAT `0x3A4` from selector `0x2B`
  to `0x00`; plant 10's two request lines disappear while the surrounding
  normalized initialization log and retained plant requests are unchanged.
- At the exact plant 10 post-call boundary `0x0044596D`, live ANM header
  indices `66/68` bound two entries at `[0x005AAB00, 0x005AABA0)`. The caller
  then writes first-entry words `+0x24/+0x26` before `0x00445B01`
  (`EXP-20260812-021`).
- `EXP-20260812-022` reproduces those values and finds no post-title CPU read
  of either entry `+0x20` dword or the adjusted first-entry dword during an
  exact 71.708-second gameplay window.
- Exact instructions `0x00445626–0x00445632` and
  `0x00445B01–0x00445B0B` show that `0x00445B01` is the common resource-ID
  loop tail. `EXP-20260812-023` requires unique plant 10 post-call
  `0x0044596D` before accepting the immediately following common-tail stop.
- In that guarded run, the two `+0x20` dwords and adjusted first-entry dword
  remain unread through this function's caller return at `0x004679C7` and the
  natural Training title (`EXP-20260812-023`).
- Two matched guarded runs find no CPU read of either plant 10 entry's exact
  `+0x00/+0x04/+0x08` dwords before this function's caller return at
  `0x004679C7` or while execution crosses the title into captured gameplay
  (`EXP-20260812-024`).
- One guarded run finds no CPU read of either exact nonzero entry `+0x0C`

- One guarded run finds no CPU read of either exact entry `+0x2E` word through

- One guarded run finds no CPU read of either exact entry `+0x28` word through

## Inferred

This is a scene resource batch loader. Character and plant semantics are
supported by exact built-in path strings, while the shared internal object
representation remains unnamed.

## Unknown

- Which level-data fields determine every resource ID.
- Capacity of the local ID list and shared arena.
- Complete meaning of the object index, selector `0x00861C84`, and tables
  populated downstream.
