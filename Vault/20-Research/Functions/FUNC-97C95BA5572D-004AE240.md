# Function 0x004AE240

## Summary

Constructs a rooted path, opens the file, obtains its size, reads that many bytes into a caller-supplied destination, closes the stream, and returns the size or zero on open failure.

## Confirmed

- Accepts a filename-like pointer and a destination-like value according to Ghidra's current decompilation. Source types are not confirmed. Evidence: `EXP-20260811-003`, address `0x004AE240`.
- Constructs a path in a 256-byte local buffer using one of two global roots and the first argument. Evidence: `EXP-20260811-003`, decompiler.
- Logs `LOAD : Loading file %s.` and calls `0x004B0730` to open the constructed path. Evidence: `EXP-20260811-003`, string `0x004E93AC`.
- Seeks to end, obtains a size, seeks to start, reads `size * 1` bytes into the second argument, and closes the stream. Evidence: `EXP-20260811-003`, call sequence plus embedded `fseek`/`fclose` error strings.
- Returns the obtained size on success and zero when opening fails. Evidence: `EXP-20260811-003`, decompiler control flow.

## Inferred

- `0x004B0730`, `0x004B15D0`, `0x004B1420`, `0x004B1170`, and `0x004B04E0` are fopen/fseek/ftell/fread/fclose-like runtime functions.
- The function loads a complete file into a buffer allocated or supplied by its caller.
- The selected global root may distinguish CD/temp/installed content modes.

## Unknown

- Encoding and normalization rules for the supplied path.
- Exact meanings of the two root-selection globals.
- Whether partial reads are detected.
- All game-code callers and file families loaded through this path.
