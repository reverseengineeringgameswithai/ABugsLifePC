# Function 0x00403A10

Closes the last unidentified callee of KU-072, using raw disassembly and the
export's decompiled text. [[EXP-20261012-001 - REA Ghidra analysis trial]]
first decoded the body.

## Confirmed (static)

- **Body (`0x00403A10`–`0x00403A35`).**
  - It takes two byte stack arguments; the caller cleans up (plain `ret`).
  - It stores them to `0x0059D9B6` (the frame index) and `0x0059D9B7` (a
    frame countdown).
  - It calls `0x00410A20(0x7D, 0, index)` through thunk `0x004016CC`.
- **`0x00410A20`.** It copies one frame of an animated strip
  (`0x0076F9B8[id]`) into the texture-atlas area that sprite entry `id`
  describes (`0x005BFD70[id]`)
  ([[EXP-20260910-008 - Replaceable Soil sign images]]). Entry 125 (`0x7D`)
  is a 41×20 area on texture page 16 (descriptor `0x004D7B48`), set by the
  shared setter `0x00456860` in every level
  ([[EXP-20261012-002 - Sprite table census]]).
- **Callers.** Each one calls it only when `0x0041A550(&Flik)` returns 0, the
  tracked-speech query
  ([[EXP-20260910-009 - Flik action pools and preview tail diagnosis]]).
  - Pickup routine `0x00417720`, at `0x004181E4`: index 8, 30 frames.
  - Creature interpreter `0x0041DC60`: index 7, 30 frames. If index 7 is
    already showing, it only resets the countdown (`0x0041E314`).
- **Per-frame updater `0x004037F0`.** It is called from the game update
  `0x004144C0`.
  - It animates entry **`0x7C`** (124, a 33×33 area on page 16) with random
    frames from table `0x004C1FDE`, through the RNG pointer `0x00599C60`.
  - It counts down `0x0059D9B7`. At zero, entry `0x7D` returns to frame 0.
    While tracked speech plays, it instead cycles random frames 2–5 every
    3–10 frames. Index 7 gives way to speech.

## Inferred

Entries `0x7C` and `0x7D` behave like Flik's eyes (random blinks and glances)
and mouth (lip flap during speech). `0x00403A10` would then show a brief mouth
expression: frame 8 on a pickup, frame 7 on a creature event. Page 16 is not
yet tied to Flik's model texture.

- an offline render of page 16's frames for `0x7C` and `0x7D`.
