# Function 0x004B1670

## Summary

PE entry point and runtime startup path. It prepares process/runtime state and dispatches through a thunk to `0x0043DA40`. The target's game-level role is not yet established.

## Confirmed

- The PE image base is `0x00400000`, entry RVA is `0x000B1670`, and entry VA is `0x004B1670`. Evidence: `EXP-20260811-003`, PE headers.
- Ghidra finds no callers and identifies calls to `GetVersion`, `GetCommandLineA`, `GetStartupInfoA`, and `GetModuleHandleA`. Evidence: `EXP-20260811-003`, address `0x004B1670`.
- After parsing the command-line tail and startup show state, it calls thunk `0x00401866`, whose target is `0x0043DA40`, then passes the result to an exit path. Evidence: `EXP-20260811-003`, decompiler/call references.
- The game-level parser reached from `0x0043DA40` recognizes only
  `cheat/log/mpeg/high`; the separate DSStream parser recognizes only
  `PLAY/LOOP/CLOSE/STICKY/GLOBAL`. Neither supplies a renderer option.
  Evidence: `EXP-20260816-143`, exact retail static audit.
