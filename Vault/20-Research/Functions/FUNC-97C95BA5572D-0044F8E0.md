# Function 0x0044F8E0

## Summary

Reads a stream pointer from shared entry `+0x20`, walks two bounded variable
record shapes, and transforms their values. Renderer selector 1 emits into a
software-renderer `0x80`-stride arena shared with `0x0045A7F0`; selector 2
instead calls two Direct3D batch builders.

## Confirmed

- `0x0044F8E0` loads its first argument and `0x0044F8EA` reads pointer
  `S = *(entry + 0x20)`.
- `0x0044F8EE` reads byte `S + 3`. Masked values `0x34` and `0x3C` select
  walks with exact strides `0x24` and `0x30`, respectively.
- A zero selector byte reaches the word test at `0x004509E6`; word value `1`
  advances `S` by four bytes and resumes, while another value returns.
- For the two exact accepted M2.20 files, `EXP-20260813-037` independently
  applies that walk inside all 24 retained file intervals. Both files have
  identical selector modes, record starts, and terminal offsets; all 2,102
  retained-stream differences lie in reached record spans across exact
  candidate entries `{0-7, 9-23}`. No continuation or bound contradiction
  occurs. Record-span reach is not an individual-byte-read claim.
- On the conditional output branch, representative paths allocate
  `*(0x0081BC28) + *(0x008082C8) * 0x80`, increment `0x008082C8`, store a
  prior-list pointer at output `+0x70`, store a flag word at output `+0x74`,
  and link through the head array reached via `0x004E8CC8`.
- The exact selector-1 software output arena, counter/capacity, transform
  scratch, and list-root topology are also used by `0x0045A7F0`
  (`EXP-20260813-036`, corrected by `EXP-20260813-039`).
- `0x0044F94A-0x0044F963` and `0x00450265-0x00450270` select output paths by
  `0x0059F7F0`. Value 1 reaches the software arena writers. Value 2 calls
  `0x00405FE0` through thunk `0x00401D66` at `0x0044F99D` for masked record
  `0x3C`, or `0x00407450` through thunk `0x00401CCB` at `0x0045029F` for
  masked record `0x34`.
- Both selector-2 callees append to Direct3D vertex/index batch storage and
  can flush through `0x004056A0/0x004058D0` to the device
  `DrawIndexedPrimitive` vtable slot (`EXP-20260813-039`).
- `EXP-20260813-041` maps both complete retained cycles in all three M2.27
  arms back to exact file offsets/forms. All 145 changed records inside the
  13-entry set reach one of the two selector-2 calls. The only 15 pre-call
  omissions among all 183 walked records are the `0x3C` records in entries
  21–23, already outside that set.
- For exact record `0x0A6C`, `EXP-20260813-043` maps 12 differing bytes in
  four three-byte spans into direct args 3, 6, 12, and 9 at
  `0x0044F99D`. The page/index argument depends only on unchanged record
  `+0x2F`; both files also produce the same sign/zero-derived mode at
  `0x0055C794`. Partial-register copies of changed high halves into args 2,
  5, 8, and 11 are discarded by the builder's low-word reads.
- `EXP-20260813-044` proves that the existing selector data watch stops at
  next PC `0x0044F951` with `ESI=S`, before this caller writes exact mode 2
  and before call `0x0044F99D`. The intervening caller instructions do not
  change the builder's non-source admission inputs, so that accepted data-
  watch boundary can support transient predicate evaluation without a new
  execution point.

## Inferred

This is a shared-entry stream consumer with rendering-related transforms and
separate native-software and Direct3D output routes. The exact Direct3D route
is confirmed structurally, but its contribution to the M2.20 visible result
remains inferred. The name does not assign an asset, primitive, or `.ALL`
field meaning.
