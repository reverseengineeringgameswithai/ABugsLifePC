# Function 0x00416890

## Summary

Renders several in-level HUD/status elements. Its grain-counter path reads
byte global `0x0059D9B1`, computes decimal tens and ones, caches them at
`0x00599ABE`, and draws both digits.

## Confirmed

- `0x00416BB7` reads counter byte `0x0059D9B1`.
- `0x00416BC2` compares the counter with 49 for a display-animation phase; it
  does not write or saturate the counter.
- `0x00416BEA` and `0x00416C02` call the digit draw path from the cached bytes.
- `0x00416C2C` reads the counter and uses division/remainder by 10.
- In `EXP-20260814-112`, retained count 51 produced cache word `0x0105`, bytes
  `(5,1)`, and the HUD path continued without an executable patch.
- The retail letter path reads mask byte `0x0059D9B2`, draws four slots from
  `0x00416DF9`, and tests completion against `0x0F` at `0x00416DDD`.
- `EXP-20260815-114` redirects only that draw span to helper `0x004BBA00`,
  changes the completion literal to `0xFF`, and renders eight centered slots at
  x `64,88,112,136,160,184,208,232`. The exact final executable retains the
  same grain digit path and natural tally acceptance retains `51/50`.

## Inferred

The two cached bytes are the displayed tens and ones digits for the grain
counter. The proposed name remains candidate-scoped because this function also
renders other HUD/status elements whose full contract was not mapped.

## Unknown

- Full meanings of the other status globals and draw branches.
- Display behavior at values above two decimal digits; no such value was
  needed or tested.
- General letter words, slot counts, glyph families, or layout beyond exact
  eight-slot `FLIKFLIK`.
