# Function 0x00448010

## Summary

Appends `.all` to a supplied resource base path, loads the file into a shared
arena cursor, and immediately interprets file-relative tables into a shared
runtime array.

## Confirmed

- Appends `.all` from `0x004DE028` in a 100-byte local buffer and calls whole-
  file loader thunk `0x00401082` at `0x00448079`.
- Does not retain or compare the loader's returned byte size.
- Interprets the first loaded dword as a value multiplied by two to locate a
  counted table, walks observed `0x4C`-byte descriptors, and advances the
  supplied arena cursor by embedded dword values multiplied by two.
- Copies selected fields and buffer pointers into the shared array rooted at
  `0x005A9660` with observed `0x50`-byte stride. Evidence:
  `0x00448083–0x0044818B`, `EXP-20260812-015`.
- For exact unchanged `CHARS/FLICK.ALL` and M2.20 replacement source
  `CHARS3/FLICKD.ALL`, the doubled first dword selects a 30-count table at
  file offset `0x2C00`. Thirty `0x4C`-byte source descriptors end exactly at
  file size `0x34EC`; comparison values produce 25 materialized entries
  across `[0x005A9660, 0x005A9E30)`. The coordinator then consumes/excludes
  final entry 24, leaving retained header range `[0,24)` or
  `[0x005A9660, 0x005A9DE0)` (`EXP-20260812-034`).
- For that same exact file, the source lengths consumed at
  `0x00448171-0x00448181` sum to `0x15FE`; doubled plus the initial four bytes
  equals table offset `0x2C00`. This is an exact cursor boundary, not a field
  meaning or cross-file layout claim.
- `EXP-20260813-037` applies that same exact arithmetic to both accepted files
  and maps retained descriptors 0-23 to contiguous file interval
  `[0x0004,0x2AE8)`. Entry 8's interval is unchanged; the other 23 intervals
  contain 2,102 differences. This remains an exact-two-file result and does
  not promote a general descriptor grammar.
- Exact instructions `0x004480B4–0x004480F6` derive entry-relative `+0x20`
  from the same 0x50-byte stride and store the current arena pointer there.
  `EXP-20260812-022` reproduces plant 10 values at the resulting entry-66/67
  addresses `0x005AAB20`/`0x005AAB70`.
- `EXP-20260813-036` traces that exact `+0x20` pointer from an ID-zero retained
  entry into `0x0044F8E0` and then to a conditional shared output arena.
  `EXP-20260813-038` finds that arena inactive for every exact candidate call
  in three Direct3D arms. Together these confirm a downstream pointer role
  while leaving the active renderer route, `.ALL` field name, and source-
  record semantics unknown.
- Exact stores `0x004480DF/0x004480E5/0x004480EB/0x004480F1` copy four
  descriptor dwords to entry offsets `+0x00/+0x04/+0x08/+0x0C` before the
  `+0x20` store. `EXP-20260812-023` retains those offsets as the next bounded
  access surface without assigning meanings.
- `EXP-20260812-024` reproduces both Training plant 10 entry heads as
  `0/0/0/1`. Matched hardware windows find no read of either entry's exact
  first three dwords through resource-batch return and into post-title
  gameplay. Zero values are not classified as padding or unused.
- `EXP-20260812-025` watches the two remaining nonzero head dwords together.
  Neither exact entry `+0x0C` range is read from guarded final population
  through resource-batch return or while execution reaches a retained no-input
  title. Both values remain `1`.
- Exact store `0x00448117` populates entry word `+0x2E`, with conditional
  replacement at `0x0044812D` and increment at `0x0044813C`.
  `EXP-20260812-026` reproduces both plant 10 words as unsigned `1` and finds
  neither exact range read through the guarded return/title window.
- Exact instructions `0x00448107–0x0044810B` copy a descriptor-relative word
  into entry `+0x28`. Both exact plant 10 words are zero in the guarded
  `EXP-20260812-026` snapshots. `EXP-20260812-027` finds neither exact word
  read through resource-batch return or a no-input title; both remain zero.
  Zero is not classified as padding or unused.
- Across `EXP-20260812-022` through `EXP-20260812-027`, every exact entry
  field populated by this function and the guarded plant caller has at least
  one explicit bounded read-watchpoint window. This is not a lifetime-absence
  result and does not define unpopulated/unknown offsets.

## Inferred

This is a first consumer for `.ALL` files. It is not yet safe to assign a
stronger asset or structure name.

`EXP-20260812-018` confirms that this exact destination `.ALL` remains
accepted when its paired plant 04 `.ANM` is replaced by equal-size plant 10
bytes. That mismatch acceptance does not identify any `.ALL` field or prove a
general pairing rule.

`EXP-20260812-019` confirms that the exact equal-size plant 10 `.ALL` is also
accepted with its `.ANM` at the plant 04 pair paths. No stable start-camera
change is discriminated. This is an exact compatibility result, not a layout
or field-semantic proof.

`EXP-20260812-020` confirms that the one-byte plant 10 selector suppression
removes its `.ALL` request together with the paired `.ANM` request while
preserving initialization through `NextLife`.
