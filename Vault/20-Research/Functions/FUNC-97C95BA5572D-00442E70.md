# Function 0x00442E70

## Summary

Builds and animates the end-of-level grain tally, sets a completion state at
the 50-grain milestone, and chooses the corresponding bright versus dim
completion/emblem rendering path.

## Confirmed

- `0x00442ECA–0x00442ECF` clamp the retained grain count to 50 in the retail
  executable.
- `0x00442F01` compares the value with 50; original `0x00442F27 JNE` permits
  the completion path only on equality because the intervening moves preserve
  flags.
- The numerator uses decimal division/remainder while its denominator remains
  literal 50.
- `0x004432C1` compares the animated tally with 50; completion state selects
  the bright path reached at `0x004432EF`.
- With the exact M3.2 three-byte patch, retained count 51 sets completion flag
  1, reaches `0x004432EF` at animated count 50, continues to count 51, and
  visibly renders `51/50` with the completion UI (`EXP-20260814-112`).
- Retail letter drawing begins at `0x004430B5`; its denominator literal four is
  at `0x004431E3` and emblem gate literal four at `0x00443328`. Count consumers
  at `0x00443473`, `0x004434CD`, `0x004435A3`, and `0x004435E5` address table
  `0x004DD6C0`, whose first 16 bytes are only the four-bit popcount domain.
- `EXP-20260815-114` redirects the letter drawing to helper `0x004BBA64`, all
  four counts to a complete 256-byte popcount table at `0x004BBB40`, and both
  literals to eight. The accepted natural tally visibly renders centered
  `FLIKFLIK`, `8/8`, retained `51/50`, and the existing emblem at x=0 without
  overlap.

## Inferred

The bright path includes the original 50-grain completion/emblem presentation.
This identity is supported by the visible completion UI and state transition;
individual sprite-resource identities were not traced.

## Unknown

- Exact asset identities and drawing contract for every tally/emblem sprite.
- Persistence semantics of the completion flag beyond this tested level-end

- Whether other levels intentionally use a different effective goal despite
  sharing this function.
- Any generic word, glyph, slot-count, or emblem-asset contract beyond exact
  eight-slot Training `FLIKFLIK`.

## Later findings (2026-10-02 audit pointer)

- The Summary is narrow. EXP-20260914-007
  shows the original `0x00442E70–0x0044362B` results function lays out grain,
  letter and enemy rows with medal/question markers on the right.
- Persistence Unknown, answered at the medal-byte boundary by
  EXP-20260930-001: the function ORs bits
  1/2/4 (grain/letters/enemies) into `0x0059D8F8[word 0x00599AF8]` (reads at
  `0x00442F2C/F6A/FA4`). It keeps 1 = new or 2 = earned before in
  `[esp+0x1C/0x20/0x24]`. Save `0x00419030` and load `0x004190D0` copy the
  bytes. EXP-20260930-006 pins
  the letter local (`0x00442F07`, `0x00442F74`, `0x00442F84`).
- Path: LEVELDONE → `0x00410310(4)` → `0x004447C0` case 4 → this function
  (EXP-20260907-005, EXP-20260930-001).
- Read-only hardware found `0x00861C84` = 0 by the time results run; the
  native results loader has replaced the level identity, so a results-time
  hook cannot read the level from that global. The derived build of
  EXP-20260914-009 keyed on a cached value instead.
- `tests/test_achievements.py` executes this function to its return at two
  image bases on a derived EXE (presentation stubbed).
