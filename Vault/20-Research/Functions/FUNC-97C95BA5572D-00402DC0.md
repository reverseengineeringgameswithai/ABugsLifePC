# Function 0x00402DC0

## Summary

Address-based post-initialization state/sequence function that directly reads
the ID-zero header at `0x005B18E0`, selects one or two header pointers, and
calls `0x00445FF0` with shared-entry destination index zero. Since
EXP-20261001-002 the selected pointers are known to be Flik's `.ANM` slot
records and the selector his action state; see the 2026-10-01 section.

## Confirmed

- `0x004144C0` calls this function through thunk `0x00401019` at
  `0x00414653`.
- `0x004032F0` directly loads slot `0x005B18E0`; it selects a pointer at
  header `+0x08 + selector * 4` and calls thunk `0x00401B86` at
  `0x004032FE` with third argument zero.
- A second selected pointer can be loaded after the direct slot read at
  `0x0040330E`. The alternate branch directly loads header `+0x88` at
  `0x004033C5`; both paths converge on the same updater thunk.
- In the normal `0x0040FFC0` branch, this direct ID-zero read completes before
  the later call to M1 coordinator `0x0044D430` (`EXP-20260813-035`).

## 2026-10-01 action-state table (EXP-20261001-002)

Confirmed from fresh disassembly of retail `97c95ba5…` and the table bytes;
the full catalogue is [[PC Flik animation catalog]].

- The function chooses Flik's action state, word `0x0059D998` (Flik record
  `+0x88`), from ground contact `0x0059D992`, speeds `0x0059D948/4C`, the
  carry counter `0x0059D9B3`, timers `0x0059D98A/94/96/A2`, health
  `0x0059D9A4`, float mode `0x0059D9AE`, level-done `0x0059A5B0` and input
  `0x00599AF4`. A change of state zeroes the script position `0x0059D954`
  (`0x00403170`).
- It indexes a 35-row, 20-byte table at `0x004C1CE8`
  (`0x00403181`–`0x0040319C`): frame-script pointer, slot A, slot B, 16.16
  speed (negative = scaled by ground speed), idle-family flag. Idle fidgets
  come from three 8-entry tables at `0x004C1FA8/B8/C8`, selected by level
  index (`0x00402EE3`).
- It samples slot A at `0x004032FE` and, when different, slot B at
  `0x004033D9`; while `0x0059D996` counts down it swaps in berry-throw slots
  2, 11 or 23; while strand index `0x0059D99C` is set it samples the header's
  `+0x88` (slot 32) instead.
- Script bytes `0x82/0x83/0x85` and `0x87/0x8A/0x91` raise left/right
  footstep dust (`0x0042AA50`) and sounds 0/1 (`0x004148A0`); `0xFF n` loops
  and `0xFE` ends the action.

The name keeps `candidate_` because gameplay meanings of several states
remain inferred and no runtime arm has watched the state word.
