# Function 0x00407450

## Summary

Consumes three transformed inputs on the selector-2 path and may append
Direct3D vertex/index batch data without using the software `0x80`-stride
arena.

## Confirmed

- `0x0044F8E0` calls it through thunk `0x00401CCB` at `0x0045029F` only
  when renderer selector is 2 on masked stream-record path `0x34`.
- Its completed append path adds three `0x20`-byte vertex records and three
  indices to batch storage
  rooted through `0x004C4108` or `0x004C410C`.
- At the `0x1EE` count boundary, paths call thunks
  `0x0040127B -> 0x004056A0` or `0x00401618 -> 0x004058D0` before continuing.
- Those callees invoke the Direct3D device `+0x78` vtable slot with embedded
  diagnostics identifying `DrawIndexedPrimitive`.
- It does not reference software arena capacity `0x0081C138`, base
  `0x0081BC28`, or counter `0x008082C8`.
- `EXP-20260813-040` proves each completed append path adds three vertices and
  three indices after a `>493` precheck. In fresh accepted hardware Direct3D
  arms, selected retained-entry additions use root `0x004C4108`, page 16,
  without an in-call flush. `EXP-20260813-041` corrects the prior “call count”
  label: function entries can return without appending.
- `EXP-20260813-041` proves all `0x34` records inside M2.27's 13 entries reach
  this call in both retained cycles of all three arms. Per-form control
  envelopes retain 8 exact entry/form rows containing 27 changed `0x34`
  records. Single-record offsets `0x0174`, `0x0858`, and `0x0AA4` have
  individually discriminated bounded append outcomes.
- Native disassembly places the only successful selected vertex-count write
  at `0x00407B00`; it adds three after exactly three family-specific index
  increments. All mapped earlier admission branches reach return
  `0x00407469` or `0x00407E8C` without a selected counter change
  (`EXP-20260813-042`).
- In fresh metadata-only per-record arms, offsets `0x0174`, `0x0858`, and
  `0x0AA4` produce `1/1/1`, `1/1/1`, and `0/0/0`, not their older M2.28
  patterns. The earlier outcomes remain exact for their retained arms but are
  not source-stable across launches; no fresh replacement-local outcome is
  selected for this builder (`EXP-20260813-042`).

not assign a primitive, asset, material, or source-field meaning.
