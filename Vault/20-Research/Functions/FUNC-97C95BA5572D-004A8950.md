# Function 0x004A8950

## Summary

Candidate collision-bounds and spatial-index initializer over the runtime
terrain descriptors produced by `0x004A8410`.

## Confirmed

- Calls the terrain source loader, then walks exactly 700 runtime descriptor
  slots at `0x007F4590` with stride `0x30`.
- Selects runtime descriptor `+0x2C` values 6, 7, or 8 at
  `0x004A8A1A–0x004A8A2E`.
- Walks the descriptor `+0x10` payload as 12-byte group headers plus
  `count*0x20` cells until a negative group marker.
- **Correction (EXP-20260816-141):** the bounds tracked by the
  `0x004A8A1A` walk come from *cell* fields, not the group-header words:
  X from cell `+0x18` and `+0x18 + +0x1A`, Z from
  `(byte +0x1E << 6) + word +0x0A` and
  `(byte +0x1F << 12) + (byte +0x1E << 6) + word +0x0A`. The shifted,
  rebased results store to descriptor `+0x14/+0x24` and `+0x1C/+0x28`
  (`0x004A8B28-0x004A8B60`). For Level03 descriptors 570-578 the X result
  coincides with the earlier group-word summary; the Z result does not
  ([[Known Unknowns#KU-061 - Runtime descriptor Z-bounds derivation]]).
- Selects the source file name `terrain`/`terr1`/`terr2`/`terr3` by mode
  argument before loading; EXP-131's live pointer join pins normal
  gameplay to `TERRAIN.ALL`.
- A later pass (`0x004A8E96`) assigns each tag-6/7/8 descriptor to one
  spatial zone and builds the bucket records at `0x007F1280` (start/count
  words, union bbox) plus index word lists at `0x007FC8F0`, count
  `0x007F3D58`, consumed by height collector `0x004AC460`.
- Sets `0x007F3D30` to the static descriptor count before reserving 32 dynamic
  slots. This separates the loaded static table from later object descriptors.

## Unknown

The full cell field grammar, complete spatial-grid semantics, semantic names
for descriptor types 6/7/8, and the unsupported Level00 payload variants.

  reserved slots, and every loaded descriptor appears once in the buckets.
