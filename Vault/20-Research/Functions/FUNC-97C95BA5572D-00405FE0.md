# Function 0x00405FE0

## Summary

Consumes four input coordinate records on the selector-2 path, applies the
signed fixed-point scratch-matrix transform locally beginning at
`0x0040605F`, and may append Direct3D vertex/index batch data without using
the software `0x80`-stride arena.
