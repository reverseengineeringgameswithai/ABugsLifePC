# Function 0x00445FF0

## Summary

Consumes a selected pointer, fixed-point value, and starting destination
index, then writes dynamic values into `0x50`-byte shared entries rooted at
`0x005A9660`. Exact field meanings remain unknown. Since EXP-20261001-002
the selected pointer is known to be one `.ANM` slot record and the
fixed-point value a 16.16 frame position; see the 2026-10-01 section.

## Confirmed

- Thunk `0x00401B86` jumps here. `0x00402DC0` calls that thunk with a pointer
  selected from direct ID-zero slot `0x005B18E0` and starting destination
  index zero (`EXP-20260813-035`).
- `0x0044608D-0x004460AC` forms
  `0x005A9660 + destination_index * 0x50`.
- The function writes entry dwords/words at offsets including
  `+0x00/+0x04/+0x08`, `+0x10/+0x12/+0x14`,
  `+0x18/+0x1A/+0x1C/+0x1E`, and `+0x30`.
- Source values can be copied directly or interpolated from the caller's
  fixed-point low word. These are instruction-level behaviors, not semantic
  field assignments.

## Inferred

This function updates dynamic values for a selected sequence across shared
entries. The evidence does not establish a general `.ALL` layout or identify
the visible resource.

## Unknown

- Complete selected-pointer format and bounds. (Answered for retail records
  by EXP-20261001-002; see the 2026-10-01 section.)
- Exact meanings of every shared-entry field.
- Which writes are consumed by the M2.20-visible output.

## 2026-10-01 record grammar (EXP-20261001-002)

Confirmed by native disassembly of retail `97c95ba5…` and by every retail
record ([[PC Flik animation catalog]]):

- The first argument is one `.ANM` slot record. `+0x02 & 0x7FFF` is the frame
  count (`0x00446025`, `0x004460A6`), `+0x04` the part loop count, `+0x06` the
  words per frame, `+0x08` the part-list count and `+0x0A` the byte length of a
  per-part bitmask that follows the list. Frame data follows the bitmask.
- The second argument is a 16.16 frame position. The integer part selects the
  frame; a nonzero fraction interpolates toward the next frame, and the last
  frame interpolates toward frame 0.
- Per part, list value `-3` (`0x0044607E`) skips the part but consumes a
  destination entry; `-2`/`-1` (`0x00446083`/`0x00446088`) skip it without
  consuming one; any other value is a word offset into the frame.
- A driven part supplies three linear words (entry `+0x00/+0x04/+0x08`) and
  three words interpolated as 12-bit angles with wrap at ±0x800 (entry
  `+0x10/+0x12/+0x14`). When its bitmask bit is set it supplies three more
  linear words (entry `+0x18/+0x1A/+0x1C`, flag `+0x1E` = 1).
- Frame-count bit `0x8000` selects a branch that copies words 9–11 and stores a
  frame pointer at entry `+0x30`; no retail record sets it.
- Exactly four call sites exist: `0x004032FE`/`0x004033D9` (Flik, from
  `0x00402DC0`), `0x00448569` (entity types through `0x005B18E0+type*4`) and
  `0x0044CE05` (plants, `0x005B1A7C+type*4`).

The name stays `candidate_` because the meanings of the linear words, the
angles' axis order and the extra words (Flik part 8's values fit a 4.12
scale) are not yet tied to a renderer consumer.
