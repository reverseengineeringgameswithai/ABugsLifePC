# Function 0x00416100

## Summary

Builds a `-1`-terminated list of small integer IDs that `0x00445020` uses to
select numbered plant base paths.

## Confirmed

- Writes literal ID 5 first. Evidence: instructions `0x00416103–0x0041610A`.
- Scans 64 records rooted at `0x0059B628` with an observed `0x84`-byte stride,
  conditionally adding a table-derived ID. Evidence: `0x00416132–0x00416191`.
- Then reads a count through `0x005C595C`, examines an entry field at observed
  record-relative offset `+0x10`, advances by `0x10` bytes, and may add IDs
  from tables
  `0x004DE9F4`, `0x004DEA00`, `0x004DEA10`, `0x004DEA20`, or `0x004DEA30`.
  Evidence: `0x00416197–0x00416219`.
- `0x005C595C` is slot 63 of the top-record pointer table rooted at
  `0x005C5860`. For the exact Training DAT it points at the type-`0x3F` top
  record at file offset `0x4`. Selector bytes `0x2B`, `0x2B`, and `0x2C` at
  exact file offsets `0x394`, `0x3A4`, and `0x3B4` map through the executable
  tables to IDs 4, 10, and 6. Evidence: `EXP-20260812-016`.
- Each selector class advances its own executable-table cursor only when that
  class is encountered. For class `0x2B`, instructions
  `0x004161EA–0x004161FA` load through stack cursor `+0x18`, emit the signed
  word, advance the cursor by four, and store it back. Therefore a later
  `0x2B` result depends on earlier `0x2B` occurrences.
- In the exact Training DAT, changing only the second `0x2B` at `0x3A4` to
  `0x00` preserves the plant 04 requests, omits the plant 10 pair requests,
  and reaches `NextLife` under Direct3D (`EXP-20260812-020`).
- Writes `-1` after the accumulated IDs. `0x00445020` consumes the list at
  call site `0x00445601`. Evidence: `EXP-20260812-015`.

## Inferred

The function collects plant resource IDs needed by the current scene. This
name is supported by the downstream switch and exact PC path requests. The
type-`0x3F` selector participates in that selection, but complete record and
selector semantics are not identified.

## Unknown

- Complete semantics of both scanned inputs.
- The exact `LEVEL.RAW` type-35 field that contributes Level 01's early ID 7.
- Whether any first-input record or another payload field creates the still
  missing M1 placement-record-to-resource identity bridge.
- Maximum output count; the caller provides no explicit capacity argument.

## Later findings (2026-10-02 audit pointer)

- EXP-20260928-001 (static queries plus
  Unicorn execution of the original routine) refines the first scan: a
  `0x0059B628` record adds its forced model only for actor states 1 or 4, or
  flag `0x100`. Each selector `0x29`/`0x2B` row takes the next entry from
  `0x004DE9F4`/`0x004DEA10`. With one yellow and four green retired rows the
  original routine returns `5,3,4,10,9,1,-1` (`tests/test_dream_levels.py`).
- EXP-20260914-013: a hardware arm that omitted
  the model-3 request faulted at `0x0044CA3B` on a null model after loading
  only `PLANT05`; one retired selector-`0x29` row fixed it.
- The maximum output count is still not established.
- **Plant 12 is unreachable (2026-10-12, static and runtime).** Every ID this
  routine can emit comes from one of these:
  - the constant 5;
  - the seed table at `0x004DE9F0`, indexed by `(byte+0x0F >> 4) + (byte+0x0F
    & 0xF) * 4`: entries 0–15 give 1–10, and retail's low-nibble-4 bytes
    reach entries 16–18, which give 14, 13 and 11;
  - the five token lists: `0x29` `0x004DE9F4`, `0x2A` `0x004DEA00`, `0x2B`
    `0x004DEA10`, `0x2C` `0x004DEA20`, `0x2D` `0x004DEA30`. They hold 1–11,
    13 and 14.

  No table holds 12. `plants2\plant12` is referenced once, by the loader's
  case `0xC` at `0x00445A11`, in both Ghidra and a raw scan. The 574 saved
  logs load every plant 1–11, 13 and 14, but never 12. The user reports The
  Cutting Room Floor lists it as unused; the PC evidence agrees
  independently ([[EXP-20261012-006 - Creature types from the character loader]]).
- **Per-level requests (2026-10-12).** [[EXP-20261012-007 - Unused disc content checked offline]] lists them. Plant 5 is in every
  level. Plant 11 comes only from Anthill Pt 2's last seed token and from
  engine 16, which requests almost every plant. Plants 13 and 14 come from
  City Entrance, Anthill Pt 2 and Bird Nest.
