# Function 0x0041F990

## Summary

Creates an `Examining Machine` window, enumerates DirectDraw devices, evaluates Direct3D driver records, and selects screen/render configuration candidates.

## Confirmed

- Registers a window class and creates/shows/updates a window whose class/title string is `Examining Machine`. Evidence: `EXP-20260811-003`, calls and strings at `0x0041F990`.
- Calls `DirectDrawEnumerateA` with callback `0x00401B54`. Evidence: `EXP-20260811-003`, call reference.
- References explicit diagnostics for DirectDraw device selection, Direct3D hardware/software selection, fullscreen state, render mode, and screen mode. Evidence: `EXP-20260811-003`, strings `0x004C96F8` through `0x004C9174`.
- Processes a collection of device/driver records and writes selected-record pointers to globals. Evidence: `EXP-20260811-003`, decompiler at `0x0041F990`.
- At `0x00420022-0x0042002E`, maps nonzero `0x00573FF4` to renderer selector
  `0x0059F7F0 = 1` and zero to value 2. Adjacent diagnostics independently
  map value 1 to `native software render` and value 2 to `Direct3d render`.
  Evidence: native instructions and strings in `EXP-20260813-039`.

## Inferred

- The function is a machine capability probe and configuration selector.
- The created window is temporary setup UI rather than the final game window.
