# Function 0x004467E0

## Summary

Uses a caller-supplied object's first dword as a generic resource-header index
and writes zero to a fixed pattern of words in retained shared entries.

## Confirmed

- `0x004467E4-0x004467ED` loads index `I`, selects
  `0x005B18E0 + I * 4`, and reads the selected header's `+0x04` word.
- `0x004467F1-0x00446819` uses that word to address stride-`0x50` entries
  rooted at `0x005A9660` and writes zero to an exact pattern of 18 words.
- `0x0044681E-0x00446847` repeats the header selection and writes zero to
  three words in the later retained-entry region.
- Exact `I == 0` selects the validated ID-zero header end index 24.
- M2.41 classifies four fixed slot-63 calls to this function: initialization
  call `0x0042E92C` requires `I == 0x23`; calls at `0x0041C854`,
  `0x004401F5`, and `0x0046810D` are state-gated and do not test `I`.

## Inferred

This function clears a fixed per-entry state pattern. Entry and state meanings
remain unidentified.

## Unknown

- Semantic meaning of the written words.
- Which unchanged scenes reach a state-gated slot-63 zero call.
- Visible or behavioral effect of selecting ID zero here.
