# Function 0x0042F350

## Summary

Brings up DirectInput: creates the object, the keyboard device, and one device
per enumerated joystick, then writes the default key bindings through
`0x0042F0F0`.

**Extent:** `0x0042F350`-`0x0042F565` (file `0x02E750`-`0x02E965`). One `ret`,
at `0x0042F565`, followed by `nop` then `int3` padding to `0x0042F600`. Only
two branch targets leave the range: `0x004016AE` and `0x004AFEA8`.

The proposed name describes what the instructions do. No device is given a
gameplay role.

## Confirmed

- `DirectInputCreateA` at `0x0042F43D` with `hInstance` from `0x0059F730` and
  version `0x0500`; object into `0x00598B18`. Failure jumps to `0x0042F55E`.
- Keyboard: `CreateDevice` at `0x0042F45D` with the GUID at `0x004C0230`,
  device into `0x00598B20`; `SetDataFormat(0x004AFE90)` at `0x0042F471`;
  `SetCooperativeLevel([0x0059F73C], 6)` at `0x0042F489`; `Acquire` at
  `0x0042F498`; `[0x00598BC8] = 1` at `0x0042F49F` on the fully successful
  path only.
- `EnumDevices` at `0x0042F4BA` with `dwDevType 4`, callback thunk
  `0x00401979`, `pvRef 0x005987D0`, flags `1`.
- Per joystick, in the loop `0x0042F4C5`-`0x0042F551`: `CreateDevice`;
  `QueryInterface(0x004C0220)` into `0x005988D0 + i*4`;
  `SetDataFormat(0x004AEE70)`; `SetCooperativeLevel([0x0059F73C], 5)`;
  `Acquire`; `[0x00598B28 + i*4] = 1` on success.
- `[0x00598B1C] = 1` at `0x0042F558` when the enumeration path completes.
- Calls `0x0042F0F0` through thunk `0x004016AE` at `0x0042F37D`, before the
  DirectInput calls.
- Writes the eight joystick button/mask pairs at `[0x004D8490, 0x004D84D0)`
  itself, at `0x0042F388`-`0x0042F421` (instruction starts; the last store ends at `0x0042F42A`). A second writer of the same eight
  pairs, using immediates, exists at `0x0042F250`-`0x0042F2EB`.

Identifier verification, cooperative-level decoding and the full table are in
`static/exports/BIN-97c95ba5572dce63/SUBSYS-input-static-census.md`.

  `0x0042F49F` in that run. This is an inference from the gate, not a direct
  sample of `0x00598BC8`. The joystick path and `0x00598B1C` remain
  unobserved.
