# Function 0x00430DF0

## Summary

The controls configuration screen. It titles itself "define keys" or
"define buttons" and edits 14 items: eleven bindable actions, "game pad",
"restore defaults" and "accept"
([[EXP-20261018-006 - Controls configuration screen and action bits]]).

**Extent:** `0x00430DF0` to the next function at `0x00431670` (Ghidra
export bounds).

## Confirmed

- Pushes the strings "define buttons" (`0x004DA57C`) and "define keys"
  (`0x004DA590`).
- Items: the `0x18`-byte table at `0x004D9CE8` (X, Y, a zero dword, a label
  pointer at `+0x0C`, the bound key byte at `+0x11`), listed by
  `0x004D9E38` and ended by −1.
- Dispatcher `0x00430FEC`–`0x0043100E`:
  - item 11 goes to `0x004310E4`;
  - item 12 to `0x004310D0` (defaults `0x0042F0F0`, then copy back
    `0x00430B10`);
  - item 13 to `0x00431013` (write block B, `0x00431022`–`0x004310A4`);
  - items 0–10 set `0x0059EE08 = 10` and call `0x004017CB`.
- Block B copies the eleven action items' key bytes into the key table
  `0x004D8430`. It skips slot 10, Return.

## Inferred

That "game pad" switches to the joystick table ("define buttons") and that
items 0–10 wait for a key press. The arms are named by the item labels, and
their bodies were not traced.

## Unknown

`0x00430B10` behind the uncalled thunk `0x00401DF2`).
