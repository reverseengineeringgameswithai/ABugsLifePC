# Function 0x0042BA60

## Summary

Create callback of the `"DIRECTX"` event record at `0x004D81E8`. It reads the
base CD track from `cd.txt`, then calls the DirectSound bring-up, three
unidentified routines and the DirectInput bring-up, and returns 1. The Ghidra
export has no function at this address (zero direct call sites), so this
dossier comes from disassembly of the retail copy. It was created on 2026-10-02
because two dossiers already named it as related.

## Confirmed

Disassembly of retail `97c95ba5…` (2026-10-02, `r2`):

- `0x0042BA60`–`0x0042BAFE` is one function. It copies `"cd.txt"`
  (`0x004C4800`), loads it into a zeroed 1 KiB buffer through thunk
  `0x00401082` → `0x004AE240`, and on success converts it with `0x004B0BA0`;
  otherwise it uses 2.
- It stores that value to `0x004E5824` and logs `"CONFIG : Base CD track is
  %d.\n"` (`0x004D73B8`) through thunk `0x00401CF8` → `0x004ADEA0`.
- It then calls, in order: `0x00401B95` → `0x004A3480` (DirectSound bring-up),
  `0x00401C12` → `0x0049D450`, `0x00401D25` → `0x00423600`,
  `0x004010AA` → `0x00420C80` with `[0x0059F738]`, and `0x00401582` →
  `0x0042F350` (the only `DirectInputCreateA` site). It returns 1.
- Its only reference is thunk `0x00401B04` (`jmp 0x0042BA60`), stored in the
  `.data` event record `0x004D81E8` (id 3, `"DIRECTX"`), whose `+0x04` slot the
  register function calls at `0x0042DC2A`
  ([[EXP-20260817-185 - PC event subsystem static census]]).

## Inferred

- The retail Wine log `dynamic/wine/RUN-WINE-20260812-005110/bugs.log`
  (lines 164–170) prints `EVENT : Event >>>DIRECTX<<< create function called.`,
  then the `cd.txt` load and `CONFIG : Base CD track is 2.`, then `D3DAPPCREATE`
  and `Event >>>DIRECTX<<< added.` That order fits this function running as the
  create callback. It is not proof on its own: `0x0042B9C0` reads `cd.txt` and
  prints the same CONFIG line without the bring-up calls.

## Unknown

- Whether the `D3DAPPCREATE` line comes from one of these calls.
- Who calls `0x0042B9C0`, the cd.txt-only twin.
