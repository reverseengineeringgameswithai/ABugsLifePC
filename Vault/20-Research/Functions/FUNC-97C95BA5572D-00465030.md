# Function 0x00465030

## Summary

Walks the loaded `LEVEL.RAW` packet stream and dispatches record types into
runtime tables. Only its type-35 copy boundary is characterized here.

## Confirmed

- Scene initializer `0x004671D0` constructs a `LEVEL.RAW` path and calls this
  function at `0x004675AA`.
- For parsed type `0x23`, instructions `0x0046574D–0x0046576A` clear and copy
  exactly `0x700` bytes into `0x00599EB0`.
- `0x00465105-0x0046510F` clears `0xF0` dwords beginning at
  `0x0059D9C0`, exactly the complete `20 * 0x30`-byte selector-record array.
  This is a zero-only selector producer (`EXP-20260813-053`).
- The retained Training and Level 01 hardware logs report
  `LOAD: Type 35, CreatListRam.` on this content path.
- `0x0041C420` later consumes the copied region as 64 records with a
  `0x1C`-byte stride. Evidence: `EXP-20260812-016`.

## Inferred

The function is a packet parser for `LEVEL.RAW`. The internal packet grammar
and the logged `CreatListRam` label are not promoted to semantic structure
names.

## Unknown

- Complete record framing, compression contract, and bounds behavior.
- Meanings of every dispatched type and destination table.
- Type-35 locations beyond the bounded Level01 fixture below.
