# Function 0x00417720

## Summary

Walks the type-`0x3F` table at `0x005C595C`, handles multiple selector classes,
and contains the PC-native selector-`0x14` pickup path used by Training grain.
The proposed name remains candidate-scoped because the function also handles
letters and other unidentified selectors.

## Confirmed

- Reads the relocated type-`0x3F` pointer/count at `0x005C595C` and walks
  16-byte entries. Evidence: `0x00417743` and the loop bounded by the count.
- Tests entry byte `+0x0C` against literal `0x14` at
  `0x00417991–0x0041799D` and applies a selector-specific distance branch.
- The nearby normal path writes consumed sentinel `0x80000000` to entry dword
  `+0x04` at `0x00417A30`, then dispatches by selector at
  `0x00417A39–0x00417A52`.
- Selector `0x14` reaches the branch at `0x00417CCC`; after its event checks,
  `0x00417D7B–0x00417D8D` increment byte global `0x0059D9B1`.
- The exact inserted Training entry becomes the only one of three adjacent
  records whose `+0x04` dword changes to the sentinel while `0x0059D9B1`
  changes `0 -> 1` (`EXP-20260814-111`).
- Compares the resulting counter to literal `0x32` at
  `0x00417DC2–0x00417DC9` for a separate exact-50 branch.
- Controlled transitions in `EXP-20260814-112` show `49 -> 50` reaches the
  event at `0x00417DCF`, while `50 -> 51` reaches non-equality target
  `0x00417E92` with the counter retained at 51.
- Selector cases `0x10`, `0x11`, `0x12`, and `0x13` begin at `0x00417A59`,
  `0x00417AB3`, `0x00417B3B`, and `0x00417BC3`; they OR bits `1`, `2`, `4`,
  and `8` into byte `0x0059D9B2` and compare the result with `0x0F`.
- Four moved duplicate records in `EXP-20260814-113` independently enter the
  consumed sentinel and change a reset mask to `1`, `2`, `4`, or `8`, while
  each original same-selector record remains intact.
- The mask-`0x0F` equality path increments byte `0x0059D9B0` while below nine
  at `0x00417C5A–0x00417C77`. A duplicate selector-`0x11` pickup with the mask
  already 15 retains the mask and changes that byte `1 -> 2`, confirming the
  completion/reward path can repeat.
- `EXP-20260815-114` redirects the four selector OR sites to entry helpers
  `0x004BBACC`, `0x004BBAD1`, `0x004BBAD6`, and `0x004BBADB`. They preserve
  original indices 50–53 as bits `1/2/4/8` and assign appended indices 63–66
  bits `16/32/64/128`.
- Each helper clears byte `0x0086396F` and sets it only when the previous mask
  was incomplete and the resulting mask is `0xFF`. The four original reward
  gates retain their HIGHLOW relocations but compare that scratch with one.
  Exact final-hash runtime changes `0x7F -> 0xFF` with reward four/scratch one;
  an already-`0xFF` pickup retains reward four/scratch zero.

## Inferred

Selector `0x14` represents the PC Training grain collectible. This is supported
by independent PC static flow and isolated runtime consumption/counter evidence;
the PS1 comparison only seeded the test and is not load-bearing.

Selectors `0x10`–`0x13` collectively represent the four-member Training FLIK
pickup set because they converge on the mask-`0x0F` completion path. Their
individual selector-to-visible-glyph correspondence remains unconfirmed.
