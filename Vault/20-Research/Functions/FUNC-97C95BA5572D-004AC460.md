# Function 0x004AC460

## Summary

Terrain height query entry, reached through thunk `0x00401659`. Takes a
pointer to an XYZ(+w) block, collects every collision cell whose windows
contain the biased query point, then delegates height resolution to
`0x004ACA60` through thunk `0x00401717` and returns the block's updated Y.

## Confirmed

- Copies (x, y-0x600, z, w) to a stack query block; biases x/z by
  `+0x1000` for all window tests.
- Phase 1 gathers candidate descriptor indices from the zone-bucket table
  at `0x007F128C` (stride `0x14`, count `0x007F3D58`, word lists at
  `0x007FC8F0`), built by the loader pass at `0x004A8E96`.
- Phase 2 requires descriptor box admission at `+0x14/+0x1C/+0x24/+0x28`
  with `+0x2000` slack and nonzero tag word `+0x2C`, then walks payload
  groups; group windows use header words `+0x04..+0x0A` and cell windows
  use `+0x18/+0x1A` (X) and `(byte +0x1E << 6) + word +0x0A` with span
  `(byte +0x1F + 4) << 6` (Z), each with `+0x100` slack. Cell coordinates
  are `(biased - base) / 32` truncated toward zero.
- Accepted cells append to `0x007F3F50` (pointers) and `0x007F267E+2`
  (descriptor words), count `0x007FC8D4`; the resolver result lands back
  in the query block Y and mirrors to `0x007FC8E0/E4`.
- The Level03 reset consumer `0x00432930` calls it with the auxiliary
  triple `0x0059D960` and a `0x7FFFFFFF` sentinel Y, then subtracts
  `0x100` (`0x004329F1`).
