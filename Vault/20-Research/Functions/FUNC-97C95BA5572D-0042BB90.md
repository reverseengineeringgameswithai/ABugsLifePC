# Function 0x0042BB90

## Summary

Writes 40 `audio\*.wav` name pointers into the 8-byte-stride table based at
`0x00596528`, and contains the path assembly and `PLAYTRACK` log for a
selected track. Reached through thunk `0x00401DBB`; callers `0x0041A1FF`,
`0x0049D35A`, `0x0049D41B`.

## Confirmed

- **40 populated track slots**, indices0..39, use immediate and register stores;
  index40 is null and every second dword is zero. EXP-20260909-005 corrects
  the earlier immediate-only count using disassembly and original-x86 execution.
- Indices 0-14 are `Level1a`-`Level5c`, five levels by a/b/c; 17-21 are
  `levcom`, `title`, `bugs2mb`, `bugs2ma`, `bugs2mc`; 24-36 are `less1`-`less12`
  including `less8a`.
- DEAD occupies15/16/22/23; LESS13 occupies37/38/39. Register stores at
  `0x0042BBAF`..`0x0042BBBE`, `0x0042BDF8`/`0x0042BE08`/`0x0042BE13` prove it.
- Initial Training stages0..13 select cues24..37 through `0x0049D320`, with
  non-looping playback. See [[PC Mr Soil dialogue replacement]].
- A path is concatenated into `0x00596960` from `\pc\bugs\cd\` (`0x004E9070`)
  plus the selected name, then logged with the format string at `0x004D744C`
  (referenced at `0x0042BEF6`).
- The disc directory `PC/BUGS/CD/AUDIO` holds exactly 35 `.WAV` files, which
  matches the `audio\` prefix used by the strings.

## Inferred

The original music-only interpretation was incomplete. EXP-20260909-005
independently identifies actual tutorial speech files and their dispatcher.
This table serves streamed lesson speech as well as music-named tracks; the
separate SFX subsystem remains outside this packet.

## Unknown

The meaning of each entry's second dword; selection of extra aliases38/39
and non-tutorial cues; and audible replacement acceptance. All table slots
and initial tutorial selections now have native evidence.

## Later findings (2026-10-02 audit pointer)

- EXP-20260910-004 finds
  the filename load at `0x0042BE8F` (`mov edx,[esi*8+00596528]`). Entry slice
  `0x0042E9B5`–`0x0042EA31` picks cues 0–14 for carousel 1–15 (cue 21 at
  `0x0042EA15`) through thunk `0x0040162C` to `0x0049D3E0`, the third caller
  above (rechecked by disassembly 2026-10-02).
- The same experiment traces sound effects through `0x0049E3E0`/`0x0049DF90`
  and WAV loader `0x004AD950`, "not the older `0x0042B020` game-effect
  helper". That separates the effects path from this table, which the
  experiment below was meant to test; `0x0042B020` itself is still
  unidentified.
- Audible replacement: EXP-20260912-008
  hooks `0x0042BE8F` in a derived build to load a replacement music track,
  which was heard in hardware. Other cues and the second dword remain open.
