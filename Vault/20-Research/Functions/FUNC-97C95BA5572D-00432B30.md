# Function 0x00432B30

## Summary

Internal Level03/Tunnels update containing a nine-row grain-requirement loop.
The gate semantic is high-confidence inference from the exact comparisons,
coordinates, linked state changes, and EXP-129 behavior; the address remains
the authority.

## Confirmed

- Dispatcher `0x00418780` case 3 at `0x0041879B` reaches this function through
  thunk `0x00401429`; live Tunnels sets `0x00861C84 = 3`.
- Iterates nine 20-byte records at `0x004DA9C8`.
- Compares unsigned grain byte `0x0059D9B1` with each dword at record `+0x08`.
- Exact retail `+0x08` values are
  `(20,10,10,10,20,20,30,10,30)`.
- Initializer `0x00432810` copies 45 dwords from template `0x004DAA80` into
  `0x004DA9C8` using `rep movsd` at `0x00432822`.
- The row-0 open branch updates row 4 and object/animation index 4; the row-4
  branch correspondingly updates row 0. The exact static form is the
  cross-type writes `0x00432F85` (row 0 opens row 4 at `0x004DAA18`) and
  `0x00432F9D` (row 4 opens row 0 at `0x004DA9C8`)
  ([[EXP-20260815-139 - Static grain-gate trigger geometry]]).
- Row proximity uses the same sar-8 planar form as `0x00416580` inline: open
  requires squared sum below `0x2710` (about 25600 world units, identical
  for all nine rows) at `0x00432F49`; the insufficient-grain message
  requires below `0x640` (about 10240 units) at `0x00432FEB`. Grain is
  compared before distance.
- Opening sets row type `0x10C7 -> 0x1068`; any type above `0x708` then
  adds `-140` per update, settling at `0x690` — the exact lifecycle EXP-137
  observed at row 3.
- A separate 16-byte-stride region table at `0x004DAB38` earlier in the
  function selects a zone value into `0x0059EFE8` with sar-10 distance math;
  it is not a gate table (EXP-139).
- In the modified `(1..9)` profile, accepted runtime evidence at row 3's exact
  radius joins configured requirement 4 to physical behavior: grain 3 retains
  type `0x10C7` and a visibly closed gate; grain 4 settles to type `0x0690`
  and a visibly open gate with `NextLife=0` (EXP-137, independently accepted
  by EXP-138).

## Inferred

The nine records represent Tunnels grain-gate mechanisms. EXP-129's first
visible gate is associated with row 3 because its observed X/Z is about
16,420 units from row 3 and its authorized count-10 result matches row 3's
retail requirement.
