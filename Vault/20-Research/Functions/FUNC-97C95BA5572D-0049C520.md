# Function 0x0049C520

## Summary

Initializes the native software renderer and owns the capacity/base/counter
triple for the conditional `0x80`-stride output arena.

## Confirmed

- Logs `INITSOFTRENDER : Start.` and `INITSOFTRENDER : End.` and references
  embedded source path `E:\pc\BUGS\soft.cpp`.
- Main and restart dispatches call thunk `0x004014E7 -> 0x0049C520` for
  renderer selector value 1. `0x0041F990` maps value 1 to
  `native software render`.
- Writes `0x0081C138 = 0x2800` at `0x0049C65E`.
- Allocates `capacity << 7` bytes through thunk
  `0x00401992 -> 0x004ADC10` and stores the result at `0x0081BC28` at
  `0x0049C689`.
- Zeros counter `0x008082C8` at `0x0049C839` and clears 0x1000 list heads
  from the root read through `0x004E8CC8` at `0x0049C840`.

## Inferred

The `0x80`-stride arena is software-renderer output storage. Exact record
fields and list ordering remain unknown despite the high-confidence renderer
ownership.

## Unknown

- Whether every native-software output path uses this arena.
