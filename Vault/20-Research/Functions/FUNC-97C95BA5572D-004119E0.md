# Function 0x004119E0

## Summary

Initializes Direct3D renderer-side state after selector `0x0059F7F0` chooses
value 2.

## Confirmed

- The first call logs exact string `INIT : Starting Direct3D renderer.` at
  `0x004119E3`.
- Main renderer dispatch `0x0043DB15-0x0043DB31` and restart dispatch
  `0x00421358-0x00421374` call thunk `0x00401965 -> 0x004119E0` only for
  selector value 2.
- Adjacent selector diagnostics in `0x0041F990` map value 2 to
  `Direct3d render`.
- The function resets rendering bounds and state globals, including
  `0x00861DE0`, `0x00861DE4`, `0x00861DBC`, and `0x004F0370`.
- It does not write software arena capacity `0x0081C138`, base
  `0x0081BC28`, or counter `0x008082C8`.

## Inferred

This is the selected Direct3D renderer-state initializer. Broader DirectDraw,
device, surface, and viewport creation occurs in other initialization code;
this name does not claim the complete device-setup boundary.
