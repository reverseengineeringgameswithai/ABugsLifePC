# Function 0x00467E60

## Summary

Address-based function that writes one `0x30`-byte record in the bounded
array at `0x0059D9C0`. Renamed 2026-10-02 from `unknown_00467E60` to
`candidate_plant_constructor` on three independent forms: static (it fills
the 20-slot pool whose selectors `0x0044CA00` registers as plant collision,
with types from `0x004DE9F0`), native (a stomped seed's tenth countdown tick
calls it, EXP-20260906-007) and hardware (one call from a derived test room
makes the native propeller plant render, EXP-20260914-013). Its complete contract and field
semantics remain unknown.

## Confirmed

- Its only direct calls are through thunk `0x00401488` at `0x0041EDF8` and
  `0x00467DF4`.
- Both calls pass an element of fixed 64-record pool
  `[0x0059B628,0x0059D728)` with stride `0x84`.
- `0x00467EC2-0x00467EDD` derives the current destination from cursor
  `0x00599C74` and base `0x0059D9C0`; the closing loop wraps the cursor after
  slot 19 and searches for a zero selector.
- `0x00467ECC` loads a selector from four-byte entries rooted at
  `0x004DE9F0`, and `0x00467EE9` is the sole native nonzero store to the 20
  exact selectors consumed by `0x0044CA00`.
- The 20 native table selector words are
  `5,3,8,2,7,7,6,7,4,10,9,1,6,6,6,6,14,13,11,11`; none is signed `-103`.
- `0x00467F13-0x00467F20` immediately sign-extends the stored selector,
  loads `*(0x004DE9B4 + selector * 4)`, and dereferences that result.
- On the normal update route, its `0x0041EDF8` call occurs within
  `0x0041EC40`, before `0x0040FFC0` calls M1 coordinator `0x0044D430`.
  No M1 record/payload value reaches this call in the reviewed invocation

## Later findings (2026-10-02 audit pointer)

- Later work calls this the plant constructor: the `0x0059D9C0` array is the
  plant pool, and the `0x0041EDF8` call fires on a stomped seed's tenth
  countdown tick ([[EXP-20260906-007 - Plant-state collision regression]],
  [[PC seed and mushroom collision state]]). The dossier was renamed
  `candidate_plant_constructor` on 2026-10-02; see the Summary.
- EXP-20260928-001 (static queries): the
  placement pointer is pool element `+0x80`. A nonzero placement `+0x0F` byte
  `b` gives table index `(b>>4) + (b&15)*4`; otherwise colour `+0x0E` and that
  colour's token byte at `0x0059D9A8` choose it. `0x004DE9F0` holds the plant
  types. Unicorn runs of the original at two image bases give type 3 for
  colour 0 / forced `0x10` and type 1 for colour 2 / forced `0x32`
  (`tests/test_dream_levels.py`). This answers the index-form unknown for these
  inputs.

  all 20 slots full, the tail `0x00467F88`–`0x00467F9D` searches for an empty
