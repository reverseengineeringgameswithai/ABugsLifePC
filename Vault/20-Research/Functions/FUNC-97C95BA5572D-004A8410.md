# Function 0x004A8410

## Summary

Candidate terrain source-descriptor loader. It walks one bounded `.ALL`
source table and appends `0x30`-byte runtime descriptors at `0x007F4590`.

## Confirmed

- Uses file word `+0x00` as a 16-bit-word offset to the record directory.
- Reads a directory count and `0x4C`-byte source records.
- Advances the payload cursor by source `+0x00 * 2` bytes.
- Copies source base components `+0x04/+0x08/+0x0C`, then shifts each left
  five at `0x004A85C6–0x004A85DC`.
- Stores the payload pointer in runtime descriptor `+0x10` at `0x004A85C1–
  0x004A85C3` for the non-clone branch.
- Copies source low word `+0x10` to descriptor `+0x2C` and source word `+0x28`
  to descriptor `+0x2E` at `0x004A8595–0x004A85A3`.
- Source word `+0x46 == 1` selects a branch that copies a prior descriptor
  chosen through source word `+0x44`, then replaces the base tuple.
- EXP-20260816-141 pins the clone branch exactly: the clone copies the
  full `0x30`-byte descriptor registered under its `+0x44` template id
  (`rep movsd` at `0x004A8535`), overwrites `+0x00/+0x04/+0x08` with its
  own base components and `+0x0C` with its own `+0x10` dword, then shifts
  the base left five. Only non-clone records with `+0x44 >= 0` register
  template ids (`0x004A85DF`); a clone whose template id is unregistered
  branches (`jl` at `0x004A8519`) to `0x004A865B`, whose raw bytes `eb fe`
  (file `0xA7A5B`) are an infinite self-jump — the engine traps, it does
  not skip (EXP-20260816-142 correction; the reimplementation raises an
  error instead, and neither retail Level03 nor Level04 `TERRAIN.ALL`
  contains such a clone). Clones therefore inherit payload pointer,
  tag `+0x2C`, and result `+0x2E` from their template. They are the
  majority of records (Level03 `TERRAIN.ALL`: 463 of 592).

The exact Level03 call begins at runtime descriptor index zero, so source
record indices 570–578 map directly to descriptors 570–578.

## Later findings (2026-10-02 audit pointer)

- [[EXP-20260904-002 - Retail collision admission and separate XZ barriers]]
  runs this loader unstubbed on real Level01/Level03 plus `PLANTTER.ALL`.
  PLANTTER source records 0..12 become template descriptors 178..190
  (Level01) and 589..601 (Level03). Source `+0x1A` supplies the signed index
  stored at `0x007F29A6 + 2*index` (`0x004A858D`), observed as object type
  + 33. This narrows the PLANTTER Unknown above; the record's other fields
  stay unnamed. [[EXP-20260909-004 - Restore native plant collision]] reuses it.
- EXP-20260909-002: one
  descriptor per source kind below 256; high-kind records (`0x101`/`0x104`)
  consume none, so source and descriptor indices differ in general (an
  authored source 229 maps to descriptor 216). Retail Level03's three
  high-kind records are 589–591 (source `+0x10` low word, read-only
  `terrain_all.py` check in this audit), so the 570–578 identity above holds.
- Kind-`0x101` payloads are linked through `0x007F3D3C` for the movement
  coordinator ([[PC TERRAIN ALL barrier strips]]).
